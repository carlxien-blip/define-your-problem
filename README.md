# 定义问题 · Define Your Problem

用 **AI 追问**帮你挖出「真目标」。

你不填表、不做测试——只需要回答 AI 的提问。AI 会顺着「为什么」一层层往下挖，最后用一句话帮你总结出一个「具体、可衡量、能跑通闭环」的目标。

## 为什么不是「问你的目标是什么」

- 「你的目标是什么」问得太泛，答案往往是「赚钱」「成功」这种虚词，或者直接答不上来。
- 让你自己填目标，你会卡住——或者填一个「别人期望的」而不是「自己真想要的」。

所以这里换成 **AI 问、你答**：AI 负责往下挖，你只需要想到什么说什么。

## 怎么用

把这个 skill 装进你的 AI（Claude Code / Codex / WorkBuddy / 任何支持 skill 的工具），然后说一句：

> 帮我定义问题 / 我到底要做什么。

AI 会开始追问，你回答就行。聊透了，AI 会帮你总结成一句话目标：

```
你的目标：在 [平台 / 场景]，把 [具体的事]，做到 [可衡量的结果]
```

比如：不是「把亚马逊做起来」，是「在德国亚马逊，把一款宠物猫窝卖出 10 单」。

## 为什么要「只挖目标，不拆解」

目标挖出来只是第一步。怎么拆成一步步、每步该不该用 AI，需要**专业判断**——懂那个行业才拆得对。所以这个 skill 停在「挖目标」，拆解留给专业的人（或你自己去学）。
